# Проверка устойчивости калибровки отрицательных контролей

Дата протокола: 29 октября 2026 г. Протокол составлен до получения сводных результатов этого запуска; внешней пререгистрации нет.

## Область проверки

Проверяются формулы среднего и method of moments (MoM) из разделов 3.4–3.5 `manuscript_updated/manuscript.tex`. Это отдельный стресс-тест шага калибровки, не повторение опубликованных результатов рукописи, не анализ OULAD/XES и не реализация пакета Schuemie EmpiricalCalibration. Название `manuscript_mom_raw` относится исключительно к формуле данной рукописи. Установление новизны требует отдельного сопоставления с оригинальными методами.

## Генеративная модель

Для каждого студента независимо генерируются U1, U2, eta, epsilon_Y, epsilon_1,...,epsilon_6, epsilon_g ~ N(0,1).

- A = 1[w1 U1 + w2 U2 + eta > 0].
- Y = theta A + lambda_Y1 U1 + lambda_Y2 U2 + epsilon_Y.
- Ck = lambda_k1 U1 + lambda_k2 U2 + epsilon_k.
- Наблюдаемый прокси g = U1 + epsilon_g.
- Перекодированный контроль Ck* = scale_k Ck + shift_k.

У A отсутствует причинное влияние на Ck по построению. Истинный средний эффект theta равен 0 или 0.1. Исходы непрерывные: эти величины НЕ следует трактовать как изменение вероятности retention.

Оцениватель — разность средних, без корректировки на U. Двух факторов достаточно, чтобы проверить нарушение предположения об одном доминирующем факторе. A имеет частоту около 0.5; сконструированный тест не предназначен для исследования нарушения positivity. Номинальные стандартные ошибки вычисляются по influence scores, включая ковариацию целевого исхода и контролей для oracle-transfer.

## Три эксперимента

1. Один активный фактор. lambda_Y=(0.1,0); lambda_k=(s_k 0.1 r,0), s=(+,-,+,-,+,-), r=0.25,0.5,1,2,4. Дополнительно разные нагрузки с множителями (0.25,0.5,0.75,1.25,1.5,1.75), среднее которых равно 1; затем удвоенная версия. Первый дополнительный сценарий показывает, что неоднородность сама по себе не обязательно вызывает смещение, если средняя ориентированная величина совпадает с целевой.
2. w=(1,1), lambda_Y=(0.05,0.05). Контроли имеют нагрузки s_k(0.05,0.05), s_k(-0.1,0.2) либо смесь s_k(0.2,-0.1) и s_k(-0.1,0.2). Суммы нагрузок совпадают с целевой: модули истинных смещений равны. Меняется способность g=U1+noise восстановить направление суммарного смещения.
3. Однофакторная панель с равными модулями нагрузок. Все контроли умножаются на 0.1, 1 или 10; отдельно один контроль умножается на 10; проверяются сдвиг всех контролей на 100 и обращение знака всех контролей. Информация о причинном устройстве не меняется. Нелинейная перекодировка ordinal-переменных в этот запуск не входит.

Всего 16 сценариев × 2 истинных эффекта × 1000 повторений, n=4000. Во всех сценариях и для обоих эффектов используется один seed 20261029: это общие случайные числа для парных сравнений, а не независимые исследования.

## Сравниваемые процедуры

- `uncalibrated`: исходная разность средних и обычный 95% интервал.
- `manuscript_mom_raw`: вычитание среднего сырых оценок контролей; h²=max(0, sample_var(control estimates)-mean(control SE²)); интервал estimate ± 1.96 sqrt(SE_Y²+h²).
- `sign_mom`: то же после умножения на sign(corr(Ck,g)) sign(corr(Y,g)), оценённых на той же выборке.
- `standardized_sign_mom`: до MoM ориентированные оценки и их SE умножаются на SD(Y)/SD(Ck). Это простой диагностический baseline, не новый обоснованный причинный метод. SD(Y) включает вариацию лечения, поэтому baseline может зависеть от theta.
- `oracle_sign_mom`: ориентация использует известные из модели знаки истинных смещений. Это недоступный в реальности benchmark для отделения ошибки знака от ошибки величины.
- `oracle_transfer_covariance`: оценка каждого контроля умножается на известное bY/bk; для коррекции используются все ковариации influence scores. Это недоступный в реальности benchmark, показывающий роль коэффициентов переноса.

MoM-интервалы воспроизводят plug-in-формулу рукописи. Они не включают отдельную оценку неопределённости параметров эмпирического нуля, ориентации и стандартизации; h² не является стандартной ошибкой среднего панели. Поэтому покрытие здесь — эмпирическая характеристика этой формулы, а не заявленная теорема валидности. Oracle-transfer использует фиксированные известные коэффициенты; сравнение его интервалов с MoM не изолирует только выбор ориентации.

## Аналитическая истина

Delta = E[U|A=1]-E[U|A=0] = 2 sqrt(2/pi) w / sqrt(1+||w||²).

bY = lambda_Y' Delta, bk = scale_k lambda_k' Delta. Для фиксированных ориентаций qk остаточное смещение равно bY - mean(qk bk). Знаки корреляций с прокси в пределе определяются нагрузкой на U1; у целевого исхода дополнительно присутствует theta Cov(A,U1). Oracle-sign оставляет bY-mean(|bk|) при bY>0. Разная шкала изменяет bk, не изменяя bY.

## Метрики и файлы

Смещение, RMSE, покрытие 95% интервала, средняя ширина, вероятность отклонения нуля (ошибка I рода при theta=0, мощность при theta=0.1), частота ошибочной ориентации. Для смещения, покрытия и частоты отклонения записана Monte Carlo standard error (MCSE). При R=1000 MCSE покрытия 0.95 около 0.0069, максимальная MCSE доли около 0.0158. Это не доверительные интервалы для реального образовательного эффекта.

- `results/config.json`: модель, параметры, версии и хеш исходного скрипта.
- `results/summary.csv`: все сводные результаты.
- `results/replications.csv`: оценки и SE в каждом повторении.
- `results/population_truth.csv`: точные предельные смещения из модели.
- `results/manifest.json`: длительность и контрольные суммы результатов.

Запуск (Python 3 с NumPy):

```powershell
rtk proxy python robustness_experiments/run_experiments.py
rtk proxy python robustness_experiments/render_results.py
```

Быстрая проверка алгебры, сдвига, масштаба и reverse coding:


Результаты предназначены для решения о дальнейшем исследовании. Они не подтверждают переносимость демографических контролей на retention, существование одного доминирующего конфаундера в OULAD или идентификацию причинного эффекта в реальных данных.
