## Допустимая формулировка вклада

Работа предоставляет воспроизводимое исследование условий применимости ориентации отрицательных контролей для образовательных данных: отдельно проверяет ошибки знака, несовпадение величин смещения и несовместимые скрытые факторы; связывает бинарную структурную модель с симуляциями на эмпирической структуре OULAD; показывает, почему успешные проверки внутри панели не доказывают корректность целевого причинного вывода.

## Что нельзя заявлять по этим материалам

- Первый метод negative-control calibration для бинарных исходов.
- Первый анализ неоднородных/неверных контролей, LOO или sensitivity intervals.
- Новая теорема только потому, что использованы MSE identity, triangle inequality или Hoeffding.
- Доказанная эффективность на реальном retention с известной истиной: в OULAD-profile истинный эффект известен только для искусственных исходов.
- Превосходство над COCA, proximal inference, NC-DiD или полной Schuemie calibration: они не реализованы в этом сравнении.
- Готовая новая теория с оценёнными nuisance-функциями и неизвестным переносом между популяциями. Теорема дополнения предполагает известный marginal propensity и обоснованное ограничение residual bias.

## Нерешённая задача для отдельного методологического вклада

Нужен конкретный источник дополнительной информации, который позволяет обосновать величину target/control mismatch или получить более узкий корректный интервал по сравнению с ближайшими работами. Из текущих OULAD/XES-панелей такая информация не следует. Дополнение честно усиливает эмпирический вклад и постановку вопроса; статус нового метода остаётся неподтверждённым.
