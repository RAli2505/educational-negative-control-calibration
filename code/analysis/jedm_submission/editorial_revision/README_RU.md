# Рабочая доработка после редакционного отказа

Главный документ: `manuscript_revised/main.pdf` (12 страниц).
Редактируемый источник: `manuscript_revised/main.tex`; остальные `.tex` и рисунок находятся рядом.
Подробное соответствие замечаний и изменений: `EDITORIAL_REVISION_RU.md`.

Исходная процедура ориентации и равного объединения контролей сохранена. Эта версия уточняет её условия и ограничения; она не объявляет замечание о сопоставимости полностью устранённым.

## Проверки и воспроизводимость

- `data_inventory.py` проверяет найденные входы и архивные контрольные суммы.
- `run_real_data_audit.py` выполняет новые проверки OULAD и именованного исходного XES3G5M на общем наборе корректирующих признаков.
- `bootstrap_orientation.py` проверяет устойчивость знаков OULAD.
- `build_revision_evidence.py` формирует таблицы, рисунок и пояснительную записку из сохранённых результатов.
- `evidence/` содержит агрегированные результаты, конфигурации и контрольные суммы.
- В архив включены исходники бинарной симуляции и её сводные результаты из `effectiveness_validation/`.

Реальные данные в архив не включены. Для повторного расчёта нужны локальные входы и исходные модули по путям, указанным в скриптах и инвентаризации. Это пакет рукописи и доказательных материалов, а не автономный контейнер с данными. Использовались Python 3.12, NumPy, pandas, scikit-learn, XGBoost и pyarrow; точные версии сохранены в манифесте. Генератор рисунка требует matplotlib.

PDF собран локальным pdflatex, проверены 12 визуализированных страниц и отсутствие неразрешённых ссылок. Старые материалы `manuscript_updated` не перезаписаны.

Статус: рабочая научная редакция для обсуждения авторами. Приём журналом и достаточная для него новизна не установлены. Неблагоприятные результаты OULAD сохранены.
