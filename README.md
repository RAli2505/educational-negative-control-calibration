# Negative-control calibration in educational data

This repository contains analyses and simulations examining negative-control calibration, including applications using OULAD and XES3G5M.

## Repository structure

- \`code/data/\` contains dataset loaders and preprocessing.
- \`code/models/\` contains outcome and treatment-effect models.
- \`code/analysis/\` contains observational analyses and panel diagnostics.
- \`code/simulations/\` contains known-truth and semi-synthetic experiments.
- \`code/reporting/\` contains scripts used to produce tables and reports.
- \`results/\` contains saved numerical outputs and \`results/figure/\` contains figures.

## Data and execution

Obtain OULAD and XES3G5M separately. The scripts came from a larger project and require adaptation of paths and imports for this structure. Complete reproduction in a clean environment has not been verified.
